## 그림 노트 보는 법

`visual-notes/index.html`을 브라우저로 열면 돼요. 장 이동은 왼쪽 목록에서 해요.

```
visual-notes/
  index.html      화면 + 스타일
  app.js          그림 렌더러 (내 필기 문법)
  data/chNN.js    장별 카드 데이터
  my-notes/       사이트에 붙는 내 필기 사진 사본
```

## 공부 루프

1. 장을 열고 그림 한 장을 골라요.
2. 공책에 옮겨 그려요. 그림 먼저 그리고, 불릿은 내 말로 줄여 써요.
3. 다 쓴 필기는 사진으로 찍어 `notes/`에 넣어요.
4. Claude에게 "등록해줘"라고 해요. 해당 카드에 `mine` 항목이 붙고, 빠지거나 틀린 부분이 있으면 Claude가 알려줘요.

## 내 필기 문법

- 제목: 주황 형광펜
- 핵심 그림: 연두 형광펜 박스로 감쌈. 그림이 먼저, 글은 아래
- 흐름: 화살표(→). 입출력은 타원, 처리 단계는 사각형
- 설명: `·` 불릿에 ① ② 번호. "용어 : 짧은 정의" 형태
- 키워드: 민트 밑줄
- 빨간 펜: 내 주석과 결론 ("*결국 ~이 본질")
