# AI Study · 딥러닝 연구 일지

> 이해했다고 믿는 것과 손으로 다시 그릴 수 있는 것은 다르다.
> 이 일지는 그 차이를 줄이기 위한 기록이다.

---

## 1. 연구 대상

『케라스 창시자에게 배우는 딥러닝 **개정 3판**』 (프랑소와 숄레 지음) 전 20장.

텐서와 경사 하강법에서 출발해 트랜스포머, LLM, 디퓨전까지 다루는 책이다.
처음에는 2판으로 시작하였으나 첫날 3판으로 바꾸었다.

## 2. 연구 목적

1. 책의 긴 서술을 **그림 한 장 + 짧은 불릿**으로 압축할 수 있을 때까지 이해한다.
2. 그 압축본을 공책에 손으로 옮겨 그리고, 원문과 대조해 빠진 것과 틀린 것을 찾는다.
3. 각 장의 코드를 직접 돌려 보며 설명을 검증한다.

## 3. 방법

하나의 개념은 다음 순서를 거친다.

| 단계 | 하는 일 | 남는 것 |
|---|---|---|
| ① 채집 | 장을 열고 그림 노트 한 장을 고른다 | — |
| ② 전사 | 공책에 옮겨 그린다. 그림이 먼저, 글은 내 말로 줄인다 | 손필기 |
| ③ 기록 | 필기를 사진으로 찍어 `notes/`에 넣는다 | 원본 사진 |
| ④ 대조 | Claude에게 "등록해줘"라고 한다. 원문과 대조해 누락과 오류를 받는다 | 카드의 `mine` 항목, 피드백 |
| ⑤ 실험 | 해당 장의 코드를 노트북으로 실행한다 | `projects/` 노트북 |

④의 피드백은 날짜별로 일지(`LOG.md`)에 적는다. 내가 틀린 부분도 지우지 않고 남긴다. 무엇을 잘못 이해했는지가 가장 쓸모 있는 기록이기 때문이다.

## 4. 기록 체계 (내 필기 문법)

공책 두 장에서 귀납적으로 뽑아낸 규칙이다. 모든 그림 노트가 이 규칙을 따른다.

- **제목**: 주황 형광펜. 개념 이름 하나만 쓴다.
- **핵심 그림**: 연두 형광펜 박스로 감싼다. 그림이 먼저, 글은 아래에 둔다.
- **흐름**: 화살표(→)로 잇는다. 입출력은 타원, 처리 단계는 사각형.
- **설명**: `·` 불릿에 ① ② 번호를 붙인다. "용어 : 짧은 정의" 형태로 쓴다.
- **키워드**: 민트 밑줄.
- **빨간 펜**: 내 주석과 결론 ("*결국 ~이 본질").
- **용어 박스**: 책이 용어 정의를 따로 모아 둔 장은 장 첫머리에 정리한다 (4 · 15 · 16장).

## 5. 자료 보관소

| 위치 | 내용 |
|---|---|
| `notes/` | 손필기 사진 원본 (+ 교재 epub, 저장소 제외) |
| `visual-notes/` | 책을 내 필기 문법으로 다시 그린 그림 노트. 20개 장, 카드 85장 |
| `projects/` | 장별 실험 노트북 (`ch03-frameworks/` …) |
| `books-practice/` | 책 실습 코드 |
| `math/` | 수학 정리 |
| `LOG.md` | 날짜별 연구 일지 (로컬 전용, 저장소 제외) |

```
visual-notes/
  index.html      화면 + 스타일
  app.js          그림 렌더러 (내 필기 문법)
  data/chNN.js    장별 카드 데이터 (+ 용어 박스)
  my-notes/       카드에 붙는 손필기 사진 사본
  data/labNN.js   실습 노트북 실행 기록 (코드 + 출력)
  lab/chNN/       실습 노트북이 그린 그래프
```

## 6. 열람 방법

- **로컬**: `visual-notes/index.html`을 브라우저로 연다. 장 이동은 왼쪽 목록에서 한다.
- **웹**: https://claude.ai/artifact/BwmWU2C8rQGUzsjdrC46xm
- **실험**: `projects/` 안의 `.ipynb`를 Jupyter나 VS Code로 열고 위에서부터 실행한다.
  실행 결과가 함께 저장되어 있어 열기만 해도 출력과 그래프를 볼 수 있다.
  그림 노트의 해당 장 첫머리에 있는 **실습 노트북** 링크로도 같은 기록을 읽을 수 있다.
